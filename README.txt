Что изменено:
1. Сервер обогащает лучшие результаты поиска данными Лабиринта.
2. Если у Лабиринта есть карточка книги, сохраняются:
   - настоящая обложка;
   - фото ph_001.jpg, где обычно виден реальный корешок книги.
3. На полке используется именно фото корешка, а не искусственно сжатая лицевая обложка.
4. При клике по книге открывается сохранённая лицевая обложка.

Файлы готовы для замены в Render/GitHub:
- server.py — заменить текущий server.py
- index.html — положить рядом с server.py (как сейчас настроен проект)
